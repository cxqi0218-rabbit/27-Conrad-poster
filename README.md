## 本地启动

在安装了 Git 和 Python 3 的电脑上运行以下命令。项目使用原生 HTML、CSS 和 JavaScript，克隆后即可启动。

```sh
git clone https://github.com/cxqi0218-rabbit/27-Conrad-poster.git
cd 27-Conrad-poster
python3 -m http.server 4173 --bind 127.0.0.1 --directory dist
```

打开 [本地海报工坊](http://127.0.0.1:4173/)。已有项目副本时，只需在项目根目录运行最后一行。

## 制作海报

1. **选择赛道。** 航空与航天、互联网科技与安全、能源与环境、健康与营养、水与可持续发展各有主题色和标识。切换赛道时，预览中的奖杯、成绩标签和时间轴会一起换色。
2. **填入课题资料。** 从「粘贴课题资料」解析现有文案，或直接编辑队名、研究方向和介绍。在样式设置里可以调整赛季、赛事标题和三条成绩。
3. **调整主视觉。** 上传 JPG、PNG 或 WebP，在预览中检查构图。图片支持 0.25–3 倍缩放和位置微调，从主图向适配专业区渐隐，即使照片较暗，专业列表也有清晰的阅读底色。
4. **核对集训安排。** 填写线上基础课程和线下项目孵化的月份。时间轴右侧预留二维码位置，可在后期排版时放入队伍二维码。
5. **导出成品。** 检查画布上的文字与日期，再选择文件格式和精度。遇到文字溢出提示时，按提示精简对应字段后导出。

## 导出与交接

| 精度 | 海报像素尺寸 | 适用场景 |
| --- | --- | --- |
| 1× | 1080 × 1650 | 快速校稿 |
| 2× | 2160 × 3300 | 屏幕展示 |
| **3× · 默认** | **3240 × 4950** | 高清分发与细节检查 |

**发送成品**可选 PNG 或单页图片版 PDF。导出时会按所选精度重新绘制文字、图标和版式。主图的细节取决于上传图片的原始分辨率。

**交接可编辑项目**请下载工程 JSON，并在另一台设备导入。文字与图片在浏览器内处理，草稿保存在当前站点的 IndexedDB。更换浏览器、切换站点地址或清理站点数据前，建议先导出工程备份。

## 维护与发布

| 路径 | 内容 |
| --- | --- |
| [dist/index.html](./dist/index.html) | 编辑器入口与表单结构 |
| [dist/styles.css](./dist/styles.css) | 工作台、预览区和移动端布局 |
| [dist/app.js](./dist/app.js) | 海报绘制、赛道配置、草稿和导出 |
| [dist/assets/](./dist/assets/) | 本地字体、赛道图标、品牌素材与原始模板 |

静态部署时，将整个 `dist/` 目录的内容发布到站点根目录，保留 `assets/` 的相对路径。使用 GitHub Pages 的部署工作流时，将 `dist/` 作为发布产物即可。
