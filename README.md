# 康莱德海报工坊

无构建依赖的网页海报编辑器。网站源文件位于 `dist/`；使用普通静态服务器即可运行，例如 `python3 -m http.server 4173 --directory dist`。

支持五个赛道主题、实时画布、图片上传与裁切、资料字段解析、IndexedDB 草稿、工程 JSON 导入导出以及 1–3 倍 PNG / 图片版 PDF 导出。用户填写的文字和上传的图片在浏览器中处理，不上传服务器。

版式来自用户提供的《27年海报模板.pdf》，尺寸为 1080 × 1650。字体采用 Noto Sans SC，可用于完整中文输入，许可证位于 `dist/assets/OFL-NotoSansSC.txt`。

橙、紫、绿、红赛道色采自康莱德官方 2025–2026 中国站学生手册中对应的单色标识；水赛道蓝色采自用户模板中的水滴标识。正文使用主色衍生的深色。官网学生手册仅作为标识来源，2027–2028 的版式、年份和成绩文案均来自用户模板，并非对未来官方赛制的声明。

参考资料：

- https://www.conradchallengechina.cn/
- https://conrad.spacecenter.org/wp-content/uploads/2025/09/2025-2026-Conrad-Challenge-China-Student-Guide.pdf

项目数据保存在当前浏览器的 IndexedDB 中。跨设备编辑请下载并导入工程 JSON；浏览器清理网站数据也会移除本地草稿。

已验证：五套赛道主题、资料解析及多段介绍、图片上传、草稿刷新恢复、超长介绍提示并阻止截字导出、390 × 844 手机布局及 1440 × 1000 桌面布局。浏览器实际生成的 2 倍 PNG 为 2160 × 3300；PDF 为 1 页、1080 × 1650 pt，已用 Poppler 重新渲染检查中文与版式。

上传图片支持 0.25–3 倍缩放。柔和融合使用透明蒙版把照片延展至介绍和专业区，与同一张海报背景连续合成；缩小后，图片自身四周的边缘也会渐变。已用 KINSO 竖图验证 0.25 倍最小值、0.65 倍草稿刷新恢复和 3240 × 4950 的 3 倍 PDF 导出。

图片背景延续至海报底边，专业区与时间轴下方保留低透明度画面。缩小后原图高度不足时，从图片最下方的背景平滑接续至底部，主体维持原来的缩放与比例。
